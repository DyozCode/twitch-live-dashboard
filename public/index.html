⚡ API Console ▲ Netlify
🚀 Setup in 4 Schritten — echte Live-Daten aktivieren
Dieses Dashboard läuft als statische Seite auf Netlify. Der Proxy (Edge Function) holt die Twitch-Daten sicher auf dem Server und gibt sie ans Dashboard weiter. Dein API-Secret bleibt dabei niemals im Browser.
SCHRITT 01
Twitch App registrieren
Öffne dev.twitch.tv/console → "Register your application"

• Name: beliebig
• OAuth Redirect URL: http://localhost
• Category: Website Integration

Danach: Client ID und Client Secret kopieren.
SCHRITT 02
GitHub Repo erstellen
Lade die Dateien aus dem twitch-live-proxy/-Ordner in ein neues GitHub-Repository hoch.

Struktur:
netlify/edge-functions/twitch-proxy.js
netlify.toml
public/index.html ← diese Datei
SCHRITT 03
Auf Netlify deployen
app.netlify.com → "Add new site" → "Import from Git" → GitHub-Repo auswählen.

Unter Site settings → Environment variables setzen:
# Deine Twitch-Zugangsdaten:
TWITCH_CLIENT_ID = abc123…
TWITCH_CLIENT_SECRET = xyz789…
SCHRITT 04
Proxy-URL eintragen
Nach dem Deploy erhältst du eine URL wie:
https://mein-dashboard.netlify.app

Im Code dieser Datei die Zeile:
const PROXY = '/api/twitch';

bleibt so — der relative Pfad funktioniert automatisch. Fertig! 🎉
